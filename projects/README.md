# projects/

One folder per project. Lowercase names, hyphens instead of spaces.

- `sample-case-study/` is the template. Copy it, do not edit it.
- Rise exports go in `<project>/rise/` (entry file: index.html)
- Storyline exports go in `<project>/storyline/` (entry file: story.html)
- Interactive HTML builds can sit directly in the project folder.

See `how-to-update.md` in the root folder.
