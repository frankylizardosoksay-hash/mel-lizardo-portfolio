Data Visualisation Explorer

Making data visualisation something learners can explore, not just observe.

Tools
Claude Design, HTML, CSS, JavaScript
Format
Interactive HTML5 learning prototype
Audience
Adult microcredential learners
Status
Prototype in development

The question

What if learners could discover how charts communicate information by interacting with them, rather than reading explanations?

The experiment

I designed a self-directed data visualisation experience where learners explore line, bar, doughnut and scatter charts using relatable datasets covering cost of living, technology and AI, and climate and energy.

Instead of presenting static examples, the interface lets learners select charts, interact with data points, reveal insights and observe animated transitions.

What I explored

  • Learning design: Replacing lengthy explanations with visual discovery and learner-controlled exploration.
  • Interaction design: Using animation and direct manipulation to make data patterns more visible.
  • AI-assisted development: Translating learning requirements into an interactive HTML5 prototype using Claude Design.
  • Accessibility: Designing for responsive layouts, keyboard navigation and reduced-motion preferences.

The approach

A dashboard-inspired interface with concise content, meaningful chart animations and independent navigation. No quizzes, scores or fixed learning pathway — just opportunities to explore and make sense of data.

The takeaway

An exploration of how AI-assisted development can support the rapid prototyping of interactive learning experiences, while keeping pedagogy, accessibility and learner agency at the centre of the design.

Mel Lizardo — learning designer, Manila, Philippines.
